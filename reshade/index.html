Important: read this first

Check each route and vehicle creator's rules before you use ReShade. Most route and train packs come with a readme, licence or usage conditions. See what the creator allows and stick to it. ReShade changes the picture, so it changes how their work looks too. Ignore the rules or use their content the wrong way and expect the creator or other players to curse you out.

重要：まず読んでください

ReShadeを使う前に、路線と車両の作者が決めたルールを必ず確認してください。 多くの路線・車両データにはreadmeやライセンス、利用条件が入っています。作者が許可した範囲で使い、ルールを守ってください。ReShadeは画像を変更するので、作者の作品の見え方も変わります。ルールを無視したり変な使い方をすると、作者や他のプレイヤーにひどく罵られるかもしれません。

Penting: baca dulu

Baca aturan dari tiap pembuat rute dan kereta sebelum pakai ReShade. Biasanya paket rute dan kereta disertai readme, lisensi, atau syarat penggunaan. Ikuti saja apa yang diizinkan pembuatnya. ReShade mengubah gambar, jadi tampilan karya mereka juga ikut berubah. Kalau aturan diabaikan atau karyanya dipakai sembarangan, jangan heran kalau pembuatnya atau pemain lain memaki kamu.

Give your BVE cab a new look with ReShade

November 22, 2026 ~9 min read BVE 5 BVE 6 ReShade 6

ReShade is a free post-processing injector that adds ambient occlusion, colour grading, sharpening and film grain on top of any DirectX 9 game. BVE Trainsim 5 and 6 both render through Direct3D 9, so a few minutes in the official setup tool is enough to change the whole look of your cab. No route, train or panel files are touched.

What ReShade adds

  • Colour correction: saturation, contrast, tint and exposure tuned to your own taste.
  • SMAA anti-aliasing that smooths the jagged edges of route objects and cab gauges.
  • Ambient occlusion, depth of field, bloom and vignette for a more photographic image.
  • Film grain, chromatic aberration and sharpening, each toggleable and adjustable.
  • Everything runs on top of BVE's own output. Settings are saved as plain .ini presets you can back up or share.

Before you start

ComponentWhat to use
BVE Trainsim 5.8BveTs5.exe · 32-bit · Direct3D 9
BVE Trainsim 6.0BveTs6.exe · 64-bit · Direct3D 9
ReShade6.x setup tool from the official site
RuntimeDirectX 9 End-User Runtime and VC++ redistributable (installed with BVE)

ReShade is developed by crosire and released under the BSD 3-clause licence. Download it only from reshade.me. Do not install ReShade binaries bundled inside random preset archives.

BVE 5 and BVE 6 use different executables and different bitness. Install ReShade separately for each one you play; one installation does not carry over to the other.

1. Download the setup tool

Open reshade.me and click Download ReShade. Run the downloaded ReShade_Setup_x.x.x.exe. The standard build is enough for BVE; choose the full add-on support build only if you specifically need add-ons.

If BVE is installed under Program Files, right-click the setup tool and choose Run as administrator so it can write into that folder.

2. Point it at the BVE executable

In the setup tool, click Browse… and select the exact .exe you normally launch:

  • BVE 5: C:\Program Files (x86)\BveTs5\BveTs5.exe
  • BVE 6: C:\Program Files\BveTs6\BveTs6.exe

Those are typical locations only. The real path depends on where you installed BVE. Use the shortcut's Open file location if you are unsure. Then click Next.

3. Choose Direct3D 9

The installer asks which rendering API the application uses. Select Direct3D 9 for both BVE 5 and BVE 6. BVE renders with SlimDX (DirectX 9) even though BVE 6 itself is a 64-bit program: the bitness changes the architecture of the ReShade DLL, not the graphics API. The setup tool picks the correct DLL for you.

BveTs5\                 BveTs6\
  BveTs5.exe               BveTs6.exe
  d3d9.dll                 d3d9.dll
  ReShade.ini              ReShade.ini
  ReShade.log              ReShade.log
  shaders\                 shaders\
  textures\                textures\

These files land next to the executable. Leave them there. ReShade loads them automatically on every launch.

4. Install a shader set

ReShade changes nothing until shaders are installed. On the shader selection step, tick at least one repository and let the setup tool download it. Start small: one or two general shader packs are plenty for a first preset. Finish the wizard and close it.

You can add more packs later by running the same setup tool again and choosing Modify / Update instead of installing from scratch.

5. Enable depth capture first (Add-ons tab)

Right after the first install, start BVE, press Home, and open the Add-ons tab. Under Generic Depth, tick Copy depth buffer before clear operations as shown below. This is what gives ReShade access to BVE's depth buffer. Without it, ambient occlusion and depth of field simply will not work.

The built-in Generic Depth add-on ships with the standard ReShade build, so you do not need the full add-on support build just for this. Leave Copy depth buffer before fullscreen draw calls unchecked unless depth effects still fail in fullscreen mode. The change applies immediately; reload the scenario if the buffer list does not refresh.

6. First launch and your first preset

  1. Start BVE normally and load a scenario with a cab view.
  2. Press Home to open the ReShade overlay. If nothing appears, click inside the BVE window first.
  3. Tick a few effects in the Home → Effects list, for example SMAA and a colour correction pass.
  4. Adjust the sliders until the image looks right from the driver's seat.
  5. Save the preset with the Save button. The .ini file is written next to the BVE executable.
  6. Press Home again to hide the overlay. The effects stay active.

No restart is needed. You can switch presets at any time from the overlay while driving.

7. Settings worth checking

SettingSuggestedWhy
Overlay toggle keyHomeShows or hides the ReShade UI.
Depth bufferGeneric Depth → Copy depth buffer before clear operationsEnable it on the Add-ons tab right after install; required for ambient occlusion and depth of field.
SMAA qualityHighInexpensive edge smoothing for route objects and gauges.
Active effectsUnder ~20 passesKeeps frame rate stable on older machines.
PresetSave as .iniEasy to back up or share with other players.

8. Troubleshooting

SymptomFix
BVE crashes on startupWrong API selected. Rerun the setup tool and choose Direct3D 9. If you installed the add-on build, switch back to the standard one.
Overlay does not appearPress Home, click inside the BVE window, and try windowed or borderless mode instead of exclusive fullscreen.
"Failed to initialize" messageRun the setup tool as administrator and reinstall the DirectX 9 End-User Runtime.
Depth effects look flatOpen the Add-ons tab and tick Copy depth buffer before clear operations under Generic Depth, then reload the scenario.
Large FPS dropDisable depth of field and ambient occlusion first, then lower SMAA quality. Save a lighter preset.
Preset will not saveBVE's folder is write-protected. Run BVE as administrator or install it outside Program Files.
Broke it after an updateRerun the same setup tool. It detects the existing install and offers Uninstall or Modify.

9. Uninstall ReShade

Use the same setup tool you installed with. Run ReShade_Setup_x.x.x.exe, pick the BVE executable you want to clean up, and choose Direct3D 9. Once the tool detects the existing installation it shows an Uninstall button instead of the install options. Click it and wait until it finishes.

  • Repeat for the other BVE version. BVE 5 and BVE 6 are installed separately.
  • If BVE sits in Program Files, run the setup tool as administrator.
  • Afterwards, check the executable's folder. If d3d9.dll, ReShade.ini, ReShade.log, shaders or textures are still there, delete them manually.
  • Save any preset .ini files you want to keep before removing those folders.

Launch BVE once after uninstalling to confirm the overlay is gone and the game still runs normally.

Known limitations

  • Depth buffer extraction on Direct3D 9 is not perfect; a few depth-based effects can look wrong in some scenarios.
  • ReShade costs some performance. Older PCs may need a smaller preset to keep the frame rate up.
  • BVE 5 is a 32-bit application, so very large presets can run into memory limits sooner than on BVE 6.
  • BVE's own screenshot function may not include ReShade effects; use ReShade's screenshot shortcut instead.
  • This guide is not affiliated with mackoy (BVE Trainsim) or crosire (ReShade).

ReShadeでBVEの運転台の見た目を変える

2026年11月22日 約9分 BVE 5 BVE 6 ReShade 6

ReShadeはDirectX 9対応ゲームにポストエフェクトを重ねられる無料のインジェクタです。BVE Trainsim 5と6はどちらもDirect3D 9で描画しているため、公式セットアップツールで数分設定するだけで運転台の印象を大きく変えられます。路線・車両・パネルファイルを編集する必要はありません。

ReShadeでできること

  • 彩度・コントラスト・色調・露出を好みに合わせて調整する色補正。
  • 路線のオブジェクトや計器のギザギザを滑らかにするSMAAアンチエイリアス。
  • アンビエントオクルージョン、被写界深度、ブルーム、ビネットなど、写真のような描写。
  • フィルムグレイン、色収差、シャープネス。それぞれ個別にON/OFFと調整が可能です。
  • すべてBVEの出力の上に重なるだけです。設定は.iniプリセットとして保存でき、バックアップや共有も簡単です。

はじめる前に

項目内容
BVE Trainsim 5.8BveTs5.exe · 32ビット · Direct3D 9
BVE Trainsim 6.0BveTs6.exe · 64ビット · Direct3D 9
ReShade公式サイトの6.xセットアップツール
ランタイムDirectX 9エンドユーザーランタイムとVC++再頒布可能パッケージ（BVEと一緒に導入済み）

ReShadeはcrosire氏が開発し、BSD 3-clauseライセンスで公開されています。reshade.meからのみダウンロードし、プリセット配布サイトに同梱されたReShade本体は使わないでください。

BVE 5とBVE 6は実行ファイルもビット数も異なります。プレイするバージョンそれぞれに個別に導入してください。一方の設定はもう一方には引き継がれません。

1. セットアップツールをダウンロード

reshade.meを開き、Download ReShadeをクリックします。ダウンロードしたReShade_Setup_x.x.x.exeを実行してください。BVEには通常版で十分です。full add-on support版は、アドオンが明確に必要な場合だけ選びます。

BVEがProgram Files配下にある場合は、セットアップツールを右クリックして管理者として実行を選び、フォルダへの書き込みを許可してください。

2. BVEの実行ファイルを指定

セットアップツールでBrowse…をクリックし、普段起動している.exeを選びます。

  • BVE 5: C:\Program Files (x86)\BveTs5\BveTs5.exe
  • BVE 6: C:\Program Files\BveTs6\BveTs6.exe

これらは一般的なパスの例です。実際の場所はインストール先によって異なります。わからない場合はショートカットのファイルの場所を開くを使ってください。その後Nextをクリックします。

3. Direct3D 9を選択

描画APIを選ぶ画面では、BVE 5・BVE 6のどちらでもDirect3D 9を選びます。BVEはSlimDX（DirectX 9）で描画します。BVE 6が64ビットアプリケーションでも、変わるのはReShadeのDLLのアーキテクチャだけで、グラフィックAPIは同じです。適切なDLLはセットアップツールが自動で選びます。

BveTs5\                 BveTs6\
  BveTs5.exe               BveTs6.exe
  d3d9.dll                 d3d9.dll
  ReShade.ini              ReShade.ini
  ReShade.log              ReShade.log
  shaders\                 shaders\
  textures\                textures\

これらのファイルは実行ファイルの隣に置かれます。起動ごとに自動で読み込まれるので、そのままにしておいてください。

4. シェーダーをインストール

シェーダーがないとReShadeは何も変化させません。シェーダー選択の画面でリポジトリを1つ以上チェックし、ダウンロードさせます。最初は汎用シェーダーパックを1〜2個だけにしておくのがおすすめです。ウィザードを完了して閉じます。

あとから追加したい場合は、同じセットアップツールをもう一度起動し、新規インストールではなくModifyまたはUpdateを選んでください。

5. まず深度バッファの取得を有効にする（Add-onsタブ）

初回インストールの直後にBVEを起動し、Homeでオーバーレイを開いてAdd-onsタブに移動します。Generic DepthのCopy depth buffer before clear operationsにチェックを入れてください。これがないとReShadeがBVEの深度バッファを取得できず、アンビエントオクルージョンや被写界深度は動作しません。

組み込みのGeneric Depthアドオンは標準ビルドにも含まれているため、この設定だけならfull add-on supportビルドは不要です。フルスクリーンでも深度が効かない場合以外は、Copy depth buffer before fullscreen draw callsはオフのままで構いません。変更はすぐに反映されます。一覧が更新されない場合はシナリオを読み込み直してください。

6. 初回起動とプリセット作成

  1. BVEをいつも通り起動し、運転台視点のシナリオを読み込みます。
  2. HomeキーでReShadeのオーバーレイを開きます。何も出ない場合は、まずBVEのウィンドウ内をクリックしてください。
  3. エフェクトをいくつかチェックします（Home → Effects）。まずはSMAAと色補正などがおすすめです。
  4. スライダーを調整し、運転席から見て自然な画質にします。
  5. Saveボタンでプリセットを保存します。.iniファイルがBVEの実行ファイルの隣に作られます。
  6. もう一度Homeを押すとオーバーレイが消え、エフェクトは適用されたままになります。

再起動は不要です。運転中でもオーバーレイからプリセットを切り替えられます。

7. 確認しておきたい設定

設定推奨理由
オーバーレイ切替キーHomeReShadeのUIを表示・非表示にします。
深度バッファGeneric Depth → Copy depth buffer before clear operationsインストール直後にAdd-onsタブで有効にします。AOと被写界深度に必須です。
SMAA品質High路線オブジェクトや計器の輪郭を低コストで滑らかにします。
有効なエフェクト約20パス以下古いPCでもフレームレートを安定させます。
プリセット.iniで保存バックアップや他のプレイヤーとの共有が簡単です。

8. トラブルシューティング

症状対処
起動時にBVEがクラッシュするAPIの選択ミスです。セットアップツールを再実行してDirect3D 9を選びます。アドオン版を入れた場合は通常版に戻してください。
オーバーレイが出ないHomeを押し、BVEのウィンドウ内をクリックします。排他フルスクリーンではなくウィンドウ／ボーダーレスも試してください。
初期化に失敗するセットアップツールを管理者として実行し、DirectX 9エンドユーザーランタイムを再インストールします。
深度エフェクトが平面的Add-onsタブのGeneric DepthでCopy depth buffer before clear operationsにチェックを入れ、シナリオを読み込み直してください。
FPSが大きく下がるまず被写界深度とアンビエントオクルージョンを無効にし、SMAA品質も下げます。軽いプリセットを保存してください。
プリセットが保存されないBVEのフォルダが書き込み禁止です。BVEを管理者として実行するか、Program Files以外にインストールします。
更新後に動作しなくなった同じセットアップツールを再実行します。既存の導入を検出し、UninstallまたはModifyを選べます。

9. ReShadeをアンインストールする

インストール時に使ったセットアップツールをもう一度実行します。ReShade_Setup_x.x.x.exeを起動し、削除したいBVEの実行ファイルを選んでDirect3D 9を指定します。既存のインストールが検出されると、インストールではなくUninstallボタンが表示されます。それをクリックして完了まで待ちます。

  • BVE 5とBVE 6は別々に導入しているので、もう一方も同じ手順で削除します。
  • BVEがProgram Filesにある場合は、セットアップツールを管理者として実行してください。
  • 終了後、実行ファイルのフォルダを確認します。d3d9.dll、ReShade.ini、ReShade.log、shaders、texturesが残っていれば手動で削除します。
  • フォルダを消す前に、残したいプリセットの.iniファイルを退避させておきます。

アンインストール後にBVEを一度起動し、オーバーレイが消えて通常どおり動くことを確認してください。

既知の制限

  • Direct3D 9の深度バッファ取得は完全ではなく、シナリオによっては深度依存のエフェクトがおかしくなることがあります。
  • ReShadeは多少の性能を消費します。古いPCでは軽いプリセットが必要です。
  • BVE 5は32ビットアプリケーションのため、大きなプリセットではBVE 6より早くメモリ上限に達することがあります。
  • BVE標準のスクリーンショットにはReShadeのエフェクトが写らない場合があります。ReShadeのスクリーンショット機能を使ってください。
  • このガイドはmackoy氏（BVE Trainsim）およびcrosire氏（ReShade）とは無関係です。

Beri tampilan baru untuk cab BVE dengan ReShade

22 November 2026 ~9 menit baca BVE 5 BVE 6 ReShade 6

ReShade adalah injector post-processing gratis yang menambahkan ambient occlusion, color grading, sharpening, dan film grain di atas game DirectX 9. BVE Trainsim 5 dan 6 sama-sama merender lewat Direct3D 9, jadi beberapa menit di setup tool resmi sudah cukup untuk mengubah tampilan cab kamu. File rute, kereta, atau panel tidak perlu disentuh.

Yang ditambahkan ReShade

  • Koreksi warna: saturasi, kontras, tint, dan exposure sesuai selera kamu.
  • Anti-aliasing SMAA yang menghaluskan tepian objek rute dan gauge cab.
  • Ambient occlusion, depth of field, bloom, dan vignette agar gambar lebih foto-realistik.
  • Film grain, chromatic aberration, dan sharpening, semuanya bisa menyala/mati dan diatur sendiri.
  • Semua berjalan di atas keluaran BVE sendiri. Pengaturan disimpan sebagai preset .ini yang bisa dicadangkan atau dibagikan.

Sebelum mulai

ReShade dikembangkan oleh crosire dan dirilis dengan lisensi BSD 3-clause. Unduh hanya dari reshade.me. Jangan pasang biner ReShade yang ikut dibundling dalam arsip preset sembarangan.

BVE 5 dan BVE 6 memakai executable dan bitness yang berbeda. Pasang ReShade terpisah untuk masing-masing yang kamu mainkan; instalasi di satu versi tidak terbawa ke versi lainnya.

1. Unduh setup tool

Buka reshade.me lalu klik Download ReShade. Jalankan ReShade_Setup_x.x.x.exe yang terunduh. Build standar sudah cukup untuk BVE; pilih build full add-on support hanya kalau kamu memang membutuhkan add-on.

Kalau BVE terpasang di bawah Program Files, klik kanan setup tool dan pilih Run as administrator supaya bisa menulis ke folder tersebut.

2. Arahkan ke executable BVE

Di setup tool, klik Browse… dan pilih .exe yang biasa kamu jalankan:

  • BVE 5: C:\Program Files (x86)\BveTs5\BveTs5.exe
  • BVE 6: C:\Program Files\BveTs6\BveTs6.exe

Itu cuma contoh lokasi umum. Path aslinya tergantung tempat kamu menginstal BVE. Pakai Open file location pada shortcut kalau ragu. Lalu klik Next.

3. Pilih Direct3D 9

Saat installer menanyakan API rendering, pilih Direct3D 9 untuk BVE 5 maupun BVE 6. BVE merender dengan SlimDX (DirectX 9) meski BVE 6 sendiri berupa aplikasi 64-bit: bitness hanya mengubah arsitektur DLL ReShade, bukan API grafisnya. Setup tool otomatis memilih DLL yang tepat.

BveTs5\                 BveTs6\
  BveTs5.exe               BveTs6.exe
  d3d9.dll                 d3d9.dll
  ReShade.ini              ReShade.ini
  ReShade.log              ReShade.log
  shaders\                 shaders\
  textures\                textures\

File-file ini diletakkan di samping executable. Jangan dipindah, ReShade memuatnya otomatis setiap kali dijalankan.

4. Pasang kumpulan shader

ReShade tidak mengubah apa pun sebelum shader terpasang. Pada langkah pemilihan shader, centang minimal satu repository dan biarkan setup tool mengunduhnya. Mulai dari kecil: satu atau dua paket shader umum sudah cukup untuk preset pertama. Selesaikan wizard dan tutup.

Kamu bisa menambah paket lain nanti dengan menjalankan setup tool yang sama lalu memilih Modify / Update, bukan instal ulang dari awal.

5. Aktifkan depth buffer lebih dulu (tab Add-ons)

Setelah instalasi pertama, jalankan BVE, tekan Home, lalu buka tab Add-ons. Di bawah Generic Depth, centang Copy depth buffer before clear operations. Ini yang memberi ReShade akses ke depth buffer BVE. Tanpanya, ambient occlusion dan depth of field tidak akan bekerja.

Add-on Generic Depth sudah bawaan dalam build standar ReShade, jadi kamu tidak perlu build full add-on support hanya untuk ini. Biarkan Copy depth buffer before fullscreen draw calls tidak dicentang kecuali efek depth masih bermasalah dalam mode fullscreen. Perubahan langsung berlaku; muat ulang skenario kalau daftar buffer tidak refresh.

6. Jalankan pertama dan preset pertama

  1. Jalankan BVE seperti biasa dan muat skenario dengan tampilan cab.
  2. Tekan Home untuk membuka overlay ReShade. Kalau tidak muncul, klik dulu di dalam jendela BVE.
  3. Centang beberapa efek di Home → Effects, misalnya SMAA dan satu pass koreksi warna.
  4. Atur slider sampai gambar terlihat enak dari kursi masinis.
  5. Simpan preset dengan tombol Save. File .ini ditulis di samping executable BVE.
  6. Tekan Home lagi untuk menyembunyikan overlay. Efek tetap aktif.

Tidak perlu restart. Preset bisa diganti kapan saja dari overlay selagi kamu mengemudi.

9. Uninstall ReShade

Pakai setup tool yang sama seperti saat instalasi. Jalankan ReShade_Setup_x.x.x.exe, pilih executable BVE yang mau dibersihkan, lalu pilih Direct3D 9. Begitu tool mendeteksi instalasi yang ada, tombol Uninstall akan muncul menggantikan opsi install. Klik dan tunggu sampai selesai.

  • Ulangi untuk versi BVE lainnya. Instalasi BVE 5 dan BVE 6 terpisah.
  • Kalau BVE ada di Program Files, jalankan setup tool sebagai administrator.
  • Setelah selesai, cek folder executable. Kalau d3d9.dll, ReShade.ini, ReShade.log, shaders, atau textures masih ada, hapus manual.
  • Simpan dulu file preset .ini yang mau kamu simpan sebelum menghapus foldernya.

Jalankan BVE sekali setelah uninstall untuk memastikan overlay hilang dan game tetap berjalan normal.

Batasan yang diketahui

  • Ekstraksi depth buffer pada Direct3D 9 tidak sempurna; beberapa efek berbasis depth bisa terlihat salah di sebagian skenario.
  • ReShade memakan sedikit performa. PC lama mungkin perlu preset yang lebih ringan.
  • BVE 5 adalah aplikasi 32-bit, jadi preset sangat besar bisa lebih cepat menyentuh batas memori dibanding BVE 6.
  • Fitur screenshot bawaan BVE mungkin tidak menyertakan efek ReShade; gunakan shortcut screenshot milik ReShade.
