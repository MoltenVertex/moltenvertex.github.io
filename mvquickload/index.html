Make BVE load your routes faster

November 26, 2026 ~5 min read BVE 5 BVE 6 BveEX

MVquickload is a small BveEX extension that gets a route's 3D objects and textures ready while BVE is still starting up. Download one DLL, drop it into the BveEX Extensions folder, and busy routes load quicker. Nothing in your route or train files needs to change.

What it does

  • It reads the route's .x model files ahead of time, using several CPU cores at once, and has them ready before BVE asks for them.
  • Duplicate textures are sorted out in the background too, so the same image doesn't have to be decoded over and over.
  • Anything it can't handle just goes through BVE as usual, so you won't lose any objects.
  • It doesn't touch object placement or the cab. Your route looks exactly the same. It just opens sooner.

Before you start

ComponentRequirement
BVE Trainsim5.x (tested on 5.8) or 6.x
BveEX2.0 or newer, already installed
.NET Framework4.8, already on Windows 10 and 11
SetupNo config needed. BveEX picks it up automatically.

BveEX is made by automatic9045 and isn't included here. Grab it from the official releases page first, then open BVE once so BveEX can create its folders.

1. Download and unzip

Grab MVQuickLoad.zip from the panel on this page and extract it somewhere easy to find, like your Desktop. Inside is a single file, MVQuickLoad.dll. There's no config file and nothing else to set up.

2. Put it in place

  1. Close BVE first. You can't replace a DLL while BVE is using it.
  2. Open the BveEX Extensions folder. With a standard install it's C:\Users\Public\Documents\BveEx\2.0\Extensions.
  3. Paste the DLL in there. That's it. The result is shown below.
  4. Start BVE and open a route. MVquickload works quietly in the background. There's no menu or switch to turn on.
C:\Users\Public\Documents\BveEx\2.0\Extensions\
   MVQuickLoad.dll

Don't leave two versions in the folder. If you still have an older MVquickload.dll, a .disabled file, or a renamed backup, remove it first. Two copies doing the same job will clash.

3. See if it helped

Try the same route a few times with the DLL in and out. Routes with lots of 3D structures and unique textures tend to benefit most; short routes may feel the same. This build is deliberately silent, so don't expect a log file.

Troubleshooting

SymptomWhat to do
No difference at allThe route might be small, or the delay might be coming from your graphics card rather than file loading. Try a structure-heavy route.
BVE won't startMake sure BveEX 2.0+ and .NET Framework 4.8 are installed, and that there's only one MVquickload DLL in Extensions.
Can't tell it's installedThat's normal. Check the folder above. The DLL must sit directly in Extensions, not in a subfolder.
Something looks off in a routeFiles MVquickload can't read are handled by BVE as usual. Take the DLL out and reload to see if the problem is with the route itself.

MVquickloadは、BVEが路線を開くときの待ち時間を短くする小さなBveEX拡張です。DLLをExtensionsフォルダに入れるだけで、構造物の多い路線もスムーズに読み込めます。路線や車両のファイルを書き換える必要はありません。

できること

  • 路線の.xモデルを先に読み込み、複数のCPUコアを使ってBVEが使える状態に整えます。

  • うまく扱えないファイルはそのままBVEに任せるので、物件が消えることはありません。
  • 物件の配置や運転台には影響しません。見た目は同じまま、開くのが早くなるだけです。

Bikin BVE lebih cepat membuka rute

26 November 2026 ~5 menit baca BVE 5 BVE 6 BveEX

MVquickload itu ekstensi BveEX kecil yang menyiapkan objek 3D dan tekstur rute pas BVE masih sibuk loading. Cukup unduh satu DLL, taruh di folder Extensions, dan rute berat jadi lebih cepat kebuka. Nggak ada file rute atau kereta yang perlu diubah.

Yang dilakukan

  • Model .x rute dibaca lebih awal pakai beberapa core CPU, lalu disiapkan sebelum BVE memakainya.
  • Tekstur yang kembar dibenahi juga, jadi gambar yang sama nggak perlu dibaca berulang kali.
  • File yang nggak bisa ditangani tetap diserahkan ke BVE seperti biasa, jadi nggak ada objek yang hilang.
  • Penempatan objek dan cab nggak berubah. Rutenya tetap kelihatan sama, cuma lebih cepat siap.

Sebelum mulai

KomponenKebutuhan
BVE Trainsim5.x (diuji di 5.8) atau 6.x
BveEX2.0 atau lebih baru, sudah terpasang
.NET Framework4.8, sudah ada di Windows 10/11
SettingNggak ada. BveEX yang deteksi sendiri.

BveEX dibuat automatic9045 dan nggak ikut di unduhan ini. Pasang dulu dari halaman rilis resminya. Setelah itu jalankan BVE sekali supaya foldernya kebentuk.

1. Unduh dan ekstrak

Ambil MVQuickLoad.zip dari panel di halaman ini, lalu ekstrak ke tempat yang gampang dicari, misalnya Desktop. Isinya cuma satu file, MVQuickLoad.dll. Nggak ada file konfigurasi atau hal lain yang perlu disiapkan.

2. Taruh di tempatnya

  1. Tutup BVE dulu. DLL yang sedang dipakai nggak bisa ditimpa.
  2. Buka folder Extensions BveEX. Kalau standar, lokasinya C:\Users\Public\Documents\BveEx\2.0\Extensions.
  3. Tempel DLL-nya di sana. Selesai, nggak ada langkah khusus.
  4. Jalankan BVE dan buka rute. MVquickload jalan diam-diam, nggak ada menu atau tombol yang perlu diaktifkan.
C:\Users\Public\Documents\BveEx\2.0\Extensions\
   MVQuickLoad.dll

Jangan biarkan dua versi bersamaan. Kalau masih ada MVquickload.dll lama, file .disabled, atau backup dengan nama lain, hapus dulu. Dua DLL dengan fungsi sama bakal bertabrakan.

3. Cek hasilnya

Coba buka rute yang sama beberapa kali, dengan dan tanpa DLL. Rute yang banyak struktur dan tekstur unik biasanya paling kerasa, rute pendek bisa saja nggak berubah. Build ini memang sengaja nggak nulis log, jadi jangan cari file log.
