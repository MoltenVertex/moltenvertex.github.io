Give your BVE train a real 3D cab

November 1, 2026 ~8 min read BVE 5 BveEX

MVCab3D replaces the flat 2D cab image with a DirectX .x mesh pinned to the driver's eye point. Install it once in a train folder and the 3D cab follows that train on every route — no route edits and no changes to BVE itself.

What you get

  • Your own .x cab mesh drawn every frame and anchored to the default camera position.
  • The flat 2D panel and needles are hidden. If the mesh fails to load, the 2D panel comes back automatically so you can keep driving.
  • BVE's native left-click-drag view and mouse-wheel zoom keep working. An optional experimental free look is also included.
  • Static geometry only. Gauges, handles and switches must be modelled into the mesh.

Before you start

ComponentRequirement
BVE Trainsim5.x (BVE 6 untested)
BveEX2.0.8 or newer
.NET Framework4.8 (already included in Windows 10/11)
Cab modelDirectX .x mesh plus its textures

BveEX is a third-party loader by automatic9045 and is not redistributed here. Download it from the official BveEX releases page.

1. Download the plugin files

Get MVCab3D.zip from the download panel on this page and unpack it. You need the three vehicle plugin files:

  • MVCab3D.dll — the vehicle plugin.
  • VehiclePluginUsing.xml — tells BveEX to load the plugin.
  • MVCab3D.txt — the configuration file.

2. Install per train

  1. Install BveEX 2.0.8 or newer. Launch BVE once after installing so BveEX initialises its folders.
  2. Open the train folder. This is the folder that contains the vehicle's .txt file.
  3. Copy the files. Put MVCab3D.dll, VehiclePluginUsing.xml and MVCab3D.txt next to the vehicle file.
  4. Add your cab. Copy your Cab3D.x and every texture it uses into the same folder. Textures must sit next to the .x file.
  5. Point the config at the mesh. Open MVCab3D.txt and set MeshPath = Cab3D.x. A relative path is resolved from the config file's folder.
  6. Test in BVE. Load any scenario that uses this train. The 2D panel disappears and your mesh is drawn at the driver's eye point.

BveEX also accepts a vehicle-specific name such as <vehicleName>.VehiclePluginUsing.xml. Use that when a train folder contains several vehicles and you only want the cab on one of them.

3. Prepare the cab mesh

  • Format: DirectX .x, text or binary; Metasequoia saves .x natively. The easiest way is Blender: model or import your cab, then export it with the free BVE Import/Export add-on (install it from Blender's official Extensions page).
  • Units and axes: metres, with +X right, +Y up and +Z forward.
  • Origin: put (0, 0, 0) between the driver's eyes at normal seated head height, facing forward. Build the desk, walls and windows around that point.
  • Layout guide: desk about 0.7–0.8 m below the origin, front bulkhead 1–2 m ahead, side walls 1–1.5 m out.
  • Winding matters: BVE back-face culls. Flip any triangle that is invisible from the driver's seat, or enable double-sided export.
  • Lighting: include mesh normals. A mesh without normals can render black or unlit.
  • Keep it light: the mesh is drawn every frame. A few thousand triangles is fine; millions will hurt performance.

4. Configuration reference

MVCab3D.txt is plain UTF-8 text. The first line is a free-form header, then Key = Value lines; # starts a comment.

5. Troubleshooting

Check MVCab3D.log next to the DLL first. It is the fastest way to see whether the plugin loaded and which mesh path it tried.

SymptomFix
Nothing appearsCheck the log. Common causes: missing or misnamed VehiclePluginUsing.xml, wrong MeshPath, or BveEX older than 2.0.8.
Cab is black or unlitGive the mesh proper normals. Blender exports them; in Metasequoia, compute normals.
Cab floats in exterior viewsKeep ViewDetection = Panel.
Cab rotates with the viewYou set Anchor = Camera. Use CameraHome.
Free look does nothingKeep the key held while moving the mouse. Check the key name, then try ViewDetection = Always. If your BVE build overwrites the camera transform, use native left-click-drag instead.
Look snaps backExpected. The look angle is only written while the free-look key is held.
No cab on a route without structuresThe plugin hooks structure drawing. Add at least one structure to the route.
BVE errors on loadUpdate BveEX. The plugin requires 2.0.8 or newer.

6. Known limitations

  • Static geometry only. Throttle handles, brake handles and animated parts are not supported in this version.
  • No live 3D gauges yet. Model static dials into the mesh for now.
  • Free look is experimental. The native BVE drag remains the reliable fallback.
  • Free look reads the cursor without capturing it, so looking stops at the screen edge.
  • Routes with no structures may not trigger the draw hook. Add at least one structure.

BVEの車両に本物の3D運転台を

2026年11月1日 約8分 BVE 5 BveEX

MVCab3Dは、平面の2D運転台画像をDirectX .xメッシュに置き換えるプラグインです。メッシュは運転士の眼点に固定され、車両フォルダに一度入れるだけで、その車両を使うすべての路線に表示されます。路線ファイルの編集も、BVE本体の変更も必要ありません。

できること

  • 自分の.x運転台メッシュを毎フレーム描画し、既定のカメラ位置に固定します。
  • 平面の2Dパネルと計器針を非表示にします。メッシュの読み込みに失敗した場合は2Dパネルが自動で戻るため、そのまま運転を続けられます。
  • BVE標準の左ドラッグ視点移動とホイールズームはそのまま使えます。試験的なフリールックも搭載しています。
  • 静的な形状のみ対応します。計器・ハンドル・スイッチはメッシュに作り込んでください。

はじめる前に

項目要件
BVE Trainsim5.x（BVE 6は未検証）
BveEX2.0.8以降
.NET Framework4.8（Windows 10/11には標準搭載）
運転台モデルDirectX .xメッシュとテクスチャ

BveEXはautomatic9045氏によるサードパーティ製ローダーで、ここでは再配布していません。BveEX公式リリースページからダウンロードしてください。

1. プラグインファイルをダウンロード

このページのダウンロードパネルからMVCab3D.zipを取得して展開します。必要なのは車両用プラグインの3ファイルです。

  • MVCab3D.dll — 車両用プラグイン本体。
  • VehiclePluginUsing.xml — BveEXにプラグインを読み込ませる設定。
  • MVCab3D.txt — 設定ファイル。

2. 車両ごとに導入

  1. BveEX 2.0.8以降をインストールします。 インストール後にBVEを一度起動し、BveEXのフォルダを初期化させます。
  2. 車両フォルダを開きます。 車両の.txtファイルがあるフォルダです。
  3. ファイルをコピーします。 MVCab3D.dll、VehiclePluginUsing.xml、MVCab3D.txtを車両ファイルの隣に置きます。
  4. 運転台を追加します。 Cab3D.xと使用するテクスチャを同じフォルダにコピーします。テクスチャは.xファイルの隣に置いてください。
  5. 設定でメッシュを指定します。 MVCab3D.txtを開き、MeshPath = Cab3D.xにします。相対パスは設定ファイルのフォルダを基準に解決されます。
  6. BVEでテストします。 この車両を使うシナリオを読み込むと、2Dパネルが消えて運転士の眼点にメッシュが描画されます。

BveEXは<vehicleName>.VehiclePluginUsing.xmlのような車両別ファイル名にも対応しています。1つの車両フォルダに複数の車両があり、そのうち1両だけに運転台を付けたい場合に使います。

3. 運転台メッシュの準備

  • 形式: DirectX .x（テキストまたはバイナリ）。Metasequoiaは.xを直接保存できます。最も簡単なのはBlenderで制作し、無償のBVE Import/Exportアドオンでエクスポートする方法です（Blender公式Extensionsから入手できます）。
  • 単位と軸: メートル単位。+Xが右、+Yが上、+Zが前です。
  • 原点: 座席に座ったときの目の高さで、運転士の両目の中間に(0, 0, 0)を置き、前を向けます。机・壁・窓はその点を中心に配置します。
  • 配置の目安: 運転台は原点から約0.7〜0.8 m下、前面仕切りは1〜2 m前、側壁は左右1〜1.5 mです。
  • 面の向き: BVEは裏面カリングを行います。運転席から見えない三角形は表裏を反転するか、両面出力を有効にしてください。
  • ライティング: メッシュ法線を含めてください。法線がないと黒く、または暗く描画されることがあります。
  • 軽量化: メッシュは毎フレーム描画されます。数千ポリゴンなら問題ありませんが、数百万ポリゴンは動作を重くします。

4. 設定リファレンス

5. トラブルシューティング

まずDLLの隣にあるMVCab3D.logを確認してください。プラグインが読み込まれたか、どのメッシュパスを試したかを最も早く確認できます。

症状対処
何も表示されないログを確認。VehiclePluginUsing.xmlの欠落・名前違い、MeshPathの誤り、BveEX 2.0.8未満などが原因です。
運転台が黒い・暗いメッシュ法線を設定してください。Blenderは出力時に含めます。Metasequoiaでは法線を計算します。
車外視点でも運転台が浮くViewDetection = Panelのままにしてください。
視点を動かすと運転台も回るAnchor = Cameraになっています。CameraHomeを使ってください。
フリールックが効かないキーを押したままマウスを動かしてください。キー名を確認し、ViewDetection = Alwaysも試します。BVE側がカメラ行列を上書きするビルドでは、標準の左ドラッグを使用してください。
キーを離すと視点が戻る仕様です。フリールックの角度はキーを押している間だけ書き込まれます。
構造物のない路線で運転台が出ないプラグインは構造物描画にフックします。路線に構造物を1つ以上追加してください。
読み込み時にBVEがエラーになるBveEXを更新してください。2.0.8以降が必要です。

6. 既知の制限

  • 静的な形状のみです。マスコン・ブレーキハンドル・可動部はこのバージョンでは対応していません。
  • 動く3D計器は未対応です。現在は静的な計器をメッシュに作り込んでください。
  • フリールックは試験的機能です。確実な方法はBVE標準のドラッグ操作です。
  • フリールックはカーソルを捕捉しないため、画面端に達すると見回しが止まります。
  • 構造物のない路線では描画フックが呼ばれない場合があります。構造物を1つ以上追加してください。

Cab 3D sungguhan untuk kereta BVE

1 November 2026 ~8 menit baca BVE 5 BveEX

MVCab3D menggantikan gambar cab 2D datar dengan mesh DirectX .x yang dipasang pada titik mata masinis. Pasang sekali di folder kereta, dan cab 3D akan mengikuti kereta itu di semua rute — tanpa mengedit rute dan tanpa mengubah BVE itu sendiri.

Yang kamu dapat

  • Mesh cab .x milikmu sendiri, digambar setiap frame dan dipasang pada posisi kamera bawaan.
  • Panel 2D datar dan jarumnya disembunyikan. Kalau mesh gagal dimuat, panel 2D kembali otomatis supaya kamu tetap bisa mengemudi.
  • Klik-kiri-drag untuk melihat sekeliling dan zoom roda mouse bawaan BVE tetap berfungsi. Ada juga free look eksperimental sebagai opsi.
  • Hanya geometri statis. Gauge, tuas, dan sakelar harus dimodelkan ke dalam mesh.

Sebelum mulai

1. Unduh file plugin

Ambil MVCab3D.zip dari panel unduhan di halaman ini lalu ekstrak. Kamu perlu tiga file plugin kendaraan:

  • MVCab3D.dll — plugin kendaraan.
  • VehiclePluginUsing.xml — perintah agar BveEX memuat plugin.
  • MVCab3D.txt — file konfigurasi.

2. Pasang per kereta (disarankan)

  1. Pasang BveEX 2.0.8 atau lebih baru. Jalankan BVE sekali setelah instalasi agar BveEX menyiapkan foldernya.
  2. Buka folder kereta. Ini folder yang berisi file .txt kendaraan.
  3. Salin file. Letakkan MVCab3D.dll, VehiclePluginUsing.xml, dan MVCab3D.txt di samping file kendaraan.
  4. Tambahkan cab. Salin Cab3D.x dan semua teksturnya ke folder yang sama. Tekstur harus berada di samping file .x.
  5. Arahkan konfigurasi ke mesh. Buka MVCab3D.txt dan set MeshPath = Cab3D.x. Path relatif dihitung dari folder file konfigurasi.
  6. Uji di BVE. Muat skenario apa pun yang memakai kereta ini. Panel 2D hilang dan mesh digambar di titik mata masinis.

3. Menyiapkan mesh cab

  • Format: DirectX .x, teks atau biner; Metasequoia menyimpan .x secara native. Cara termudah pakai Blender: buat atau impor cab-nya, lalu ekspor dengan add-on gratis BVE Import/Export (pasang dari halaman Extensions resmi Blender).
  • Satuan dan sumbu: meter, dengan +X ke kanan, +Y ke atas, dan +Z ke depan.
  • Origin: letakkan (0, 0, 0) di antara mata masinis pada tinggi kepala saat duduk, menghadap ke depan. Bangun meja, dinding, dan jendela di sekitar titik itu.
  • Panduan tata letak: meja sekitar 0,7–0,8 m di bawah origin, sekat depan 1–2 m di depan, dinding samping 1–1,5 m ke samping.
  • Arah face penting: BVE melakukan back-face culling. Balik triangle yang tidak terlihat dari kursi masinis, atau aktifkan ekspor dua sisi.
  • Pencahayaan: sertakan normal mesh. Mesh tanpa normal bisa tampak hitam atau tidak terkena cahaya.
  • Jaga ringan: mesh digambar setiap frame. Beberapa ribu triangle tidak masalah; jutaan akan memperberat performa.

5. Pemecahan masalah

Periksa MVCab3D.log di samping DLL terlebih dahulu. Itu cara tercepat untuk melihat apakah plugin termuat dan path mesh apa yang dicoba.

GejalaSolusi
Tidak ada yang munculPeriksa log. Penyebab umum: VehiclePluginUsing.xml hilang atau salah nama, MeshPath salah, atau BveEX lebih lama dari 2.0.8.
Cab hitam atau tidak terkena cahayaBeri normal mesh yang benar. Blender mengekspornya; di Metasequoia, hitung normal.
Cab melayang di tampilan luarBiarkan ViewDetection = Panel.
Cab ikut berputar saat pandangan digeserKamu memakai Anchor = Camera. Gunakan CameraHome.

Pandangan kembali setelah tombol dilepasMemang begitu. Sudut free look hanya ditulis selama tombol ditahan.
Tidak ada cab di rute tanpa strukturPlugin mem-hook proses gambar struktur. Tambahkan minimal satu struktur ke rute.
BVE error saat memuatPerbarui BveEX. Plugin membutuhkan 2.0.8 atau lebih baru.

6. Batasan yang diketahui

  • Hanya geometri statis. Tuas throttle, tuas rem, dan bagian bergerak belum didukung di versi ini.
  • Belum ada gauge 3D yang hidup. Untuk sekarang, buat dial statis di dalam mesh.
  • Free look masih eksperimental. Drag bawaan BVE tetap menjadi cadangan yang andal.
  • Free look membaca kursor tanpa menangkapnya, jadi pandangan berhenti di tepi layar.
  • Rute tanpa struktur mungkin tidak memicu hook gambar. Tambahkan minimal satu struktur.
